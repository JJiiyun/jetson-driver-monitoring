PRECISION ANALYSIS

FP16은 왜 FP32와 큰 차이가 없었나

FP16의 의미

이미지 해상도가 아니라 모델 내부 가중치와 특징맵의 표현 정밀도를 32비트에서 16비트로 낮춥니다.

32bit

FP32

16bit

FP16

8bit

FP8

차이가 작았던 이유

  • 통합 평균 차이 약 0.40ms
  • 모델이 작아 FP16 연산 이점이 제한적
  • 전처리·후처리·커널 실행 오버헤드
  • TensorRT FP32도 이미 고도로 최적화
0.4ms를 무의미하다고 단정하지 않는다. 차량용 임베디드에서는 누적 전력과 안정성 측면의 추가 평가가 필요하다.
