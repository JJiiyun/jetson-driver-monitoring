# data 디렉터리

| 파일/경로 | 용도 |
|---|---|
| `final_test_0727_14_30.mp4` | 1080p 파라미터 기준 원본, 9,994프레임 |
| `final_test_640x360.mp4` | 최종 640×360/30 FPS 비교 영상 |
| `5_02sec.mp4`, `test_2_fclip.mp4` | 빠른 동작 확인용 짧은 영상 |
| `validation/labels/` | 검증 정답 라벨을 둘 수 있는 위치 |

영상은 개인정보와 용량 문제로 `.gitignore` 대상입니다. 팀원이 재현하려면 Git clone
후 동일한 파일명 또는 명령에 지정한 경로로 영상을 별도 복사해야 합니다.

## 압축 재현

```bash
bash scripts/resize_video_640x360.sh \
  data/final_test_0727_14_30.mp4 \
  data/final_test_640x360.mp4
```

비교 시 해상도만 기록하지 말고 codec, FPS, 프레임 수, ffmpeg 설정까지 고정합니다.
압축 후에는 `ffprobe`로 640×360, 30 FPS와 전체 프레임 수를 확인합니다.

정답 라벨의 시간축은 원본과 압축본의 시작 시각·길이가 같을 때만 그대로 재사용할
수 있습니다. 프레임 삭제나 FPS 변환으로 타임라인이 달라지면 라벨도 다시 맞춰야
합니다.
